# CHECKMATE v117 — запуск визуальной проверки

В репозитории добавлен workflow `.github/workflows/checkmate-v117-visual.yml`.

Чтобы проверить именно v117:
1. Скачай исправленный архив `CHECKMATE_classic_v117_fixed.zip` из этого чата.
2. Загрузи его в корень репозитория GitHub с именем `CHECKMATE_classic_v117.zip` (при загрузке переименуй файл именно так).
3. Открой вкладку **Actions** → **CHECKMATE v117 — gameplay and visual QA** → **Run workflow**.
4. После завершения скачай артефакты `CHECKMATE-v117-tested-build` и `CHECKMATE-v117-visual-review`.

Workflow запускает Godot 4.4.1, импорт/запуск проекта, игровые и UI-регрессионные тесты, отдельную навигацию по экранам для PNG-снимков и проверку скриншотов на дубли/чёрные кадры.

Важно: архив v117 пока не загружен в репозиторий. Без него Actions намеренно завершится с понятной ошибкой, а не возьмёт старый ZIP и не выдаст его за v117.
