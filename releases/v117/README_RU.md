# CHECKMATE v117 — исправления управления

Этот каталог содержит исходный патч двух изменений, вошедших в локальный архив CHECKMATE_classic_v117.zip.

## Изменения
1. Области всех видимых UI-контролов, кроме `MOUSE_FILTER_IGNORE`, блокируют передачу касаний 3D-доске. Это предотвращает случайные ходы при нажатии на панели голосования и другие элементы интерфейса.
2. В офлайн-матчах сторона пользователя определяется через `local_user_team`, а не через `current_team`. Сторона хода и сторона игрока — разные значения.
