# CHECKMATE v113 — режим разработчика и боты

Базовая версия: CHECKMATE v112 fixed.

Изменения в v113:
- Удалены админ-панель, отдельный экран разработчика и отдельная кнопка офлайн-ботов.
- В обычной форме входа локальная пара TheHezzer / admin включает статус разработчика.
- В режиме разработчика любой режим шахматной партии запускается локально с ботами вместо онлайн-очереди.
- Боты выбирают легальные ходы, выполняют взятия, голосуют за первого игрока и участвуют в командном голосовании.
- Фигуры игрока-разработчика выделяются голубыми кольцами.
- Выход через «ВЫЙТИ / ИГРАТЬ ГОСТЕМ» отключает режим разработчика; обычные аккаунты и гости используют онлайн-поиск.
- Сохранена поддержка управления фигурой одним пальцем из v112.

Полная сборка: CHECKMATE_classic_v113.zip (архив проекта).
Полный применимый diff находится в patches/fix_developer_bot_mode_v113.patch внутри архива.

Проверки: ZIP integrity и статические проверки исходника пройдены. Запуск Godot runtime не выполнялся: Godot отсутствует в среде.

Примечание безопасности: TheHezzer / admin — временный клиентский тестовый доступ. Перед публичным релизом заменить серверной авторизацией.
